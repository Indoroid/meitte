# pi-meitte

The pi-coding-agent extension for Meitte as a provider. Allows for the usage of the locally running endpoint server on pi-coding-agent.

```bash
pi -e ./pi-meitte/index.ts
```
Download the archive present and the extract it in the ```.pi/agent/extensions``` folder for usage on linux.

Run the local check with:

```bash
npm install
npm test
```
